# Tu Año Personal 2027

Negocio digital de numerología de entretenimiento para mujeres hispanohablantes de 30 a 55 años.
Se vende con guías en PDF y se promociona solo con TikTok orgánico.

## Documentos

- [`docs/estrategia.md`](docs/estrategia.md): público, qué lo atrae, producto, calendario y métricas.
- [`docs/plan-claude-code.md`](docs/plan-claude-code.md): plan técnico (calculadora web, generador de imágenes, publicación).
- [`docs/brief-claude-cowork.md`](docs/brief-claude-cowork.md): brief listo para pegar en Claude Cowork (marca, guías, contenido de TikTok, revisión semanal).

## Quién hace qué

| Quién | Qué |
|---|---|
| **Tú** | Elegir la marca, grabar la voz, publicar en TikTok, abrir la tienda, pegar las estadísticas cada lunes |
| **Claude Cowork** | Marca, las 9 guías en PDF, textos de la tienda, guiones, calendario, revisión semanal |
| **Claude Code** | Calculadora web, generador de imágenes para TikTok, publicación y medición |
